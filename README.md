# somecoolprojects

Projects built one by one from
https://codingchallenges.fyi/challenges/intro,
each in its own directory, docs first, then code.

Workflow per project:

1. Pick a project (user picks, or the next one in site order).
2. Reverse-engineer / analyse the original by behaviour only,
   with the user's permission for that project.
3. Report algorithms, protocols, and stack, and confirm the
   build approach with the user.
4. Write docs in `<project>/docs/` first.
5. Then write the smallest code that passes the project's tests.
6. Push that project's directory to this repo. Next project
   only starts on the user's explicit go.

Coding rules (ponytail): think before coding, state
assumptions, simplicity first, surgical changes only,
verifiable success criteria, loop until verified.
