# Coding Challenges Shared Solutions (sample index)

Sample index in the shape the Step 3 tool parses: one Markdown link per
challenge. This is NOT a live copy of the Coding Challenges Shared
repository README — it exists so the server and its tests run offline.
Point the server at a real README with `--solutions-file` or
`--solutions-url` to use live data; the parser needs no code change
for any index written as links like these.
